# NEXUS — Gaming Cafe OS Demo

Interactive front-end concept for a modern gaming cafe management system.

## Demo screens
- `index.html` — admin / cafe management portal
- `booking.html` — customer station booking flow
- `terminal.html` — player PC terminal interface

## Features in the demo
- Live station statuses and session timers
- Start-session and wallet-recharge flows
- Booking management
- Customer directory
- POS food/drink cart
- Wallets, memberships and passes
- Revenue and utilization reports
- Responsive desktop/mobile UI

This is a UI/front-end demo using sample data only. No production authentication, payments or PC-control backend are connected.
